# Rebuttal 常用句式（可改写）

**致谢与定位**  
> We thank the reviewer for the constructive comments. Below we address each point in turn.

**澄清误解**  
> We clarify that our claim is …, which differs from … . In Sec. X we show …

**补充实验**  
> Following the suggestion, we added … (Table/Fig. R1). The results indicate …

**承认局限**  
> We agree that … remains a limitation. We have added a discussion in Sec. … and plan …

**Novelty**  
> Relative to A/B, our key difference is … under the setting of …, which enables …

**Factual error（礼貌）**  
> We respectfully note that … . Prior work / our setup uses … (citation).

**提请再评**  
> We hope the additional evidence addresses the concern regarding … .
