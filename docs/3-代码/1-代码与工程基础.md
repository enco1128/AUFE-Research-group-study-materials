## 推荐工程目录

| 目录/文件 | 作用 |
|-----------|------|
| `config/` | 超参与路径 |
| `dataset/` / `dataloader/` | 数据与增强 |
| `models/` | 网络模块 |
| `metrics/` | 损失与指标 |
| `utils/` | 工具 |
| `scripts/` | 启动脚本 |
| `weights/` | checkpoint |
| `train.py` | 主入口 |

## 调试习惯

每次尽量只改一个变量；保存种子与配置；按「数据 → 预处理 → 增强 → 结构 → 超参 → 预训练」排查。
