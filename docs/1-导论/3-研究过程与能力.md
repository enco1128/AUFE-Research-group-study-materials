## 本页目标

- 记住研究主线 **TPIC → Writing → Submit**  
- 知道研究生日常要做哪些事  
- 对照七项关键能力做自我诊断  

## 六阶段主线

```text
Topic → Problem → Idea → Concrete Work → Paper Writing → Submit
```

| 阶段 | 你要交付什么 |
|------|----------------|
| **Topic** | 读透导师给的方向与种子论文；顺藤摸瓜扩文献；对代表作尝试复现 |
| **Problem** | 提出可研究的真问题（宜小题大做，忌大题小做） |
| **Idea** | 在大量阅读与复现基础上形成解法；导师帮判断与打磨，而非直接给 idea |
| **Concrete Work** | 用理论/实验证明有效；熟悉 benchmark、对比方法与代码；设计可解释实验（强/弱在何时、为何） |
| **Paper Writing** | 把故事线写清楚再分章展开 |
| **Submit** | 投稿、Rebuttal、必要时答辩 |

> **问题是科学研究的心脏。** 找到有价值的问题，往往已经成功了一半；独立找问题的能力，是独立研究能力的标志。

### Topic 阶段三件事

1. 深入阅读导师推荐论文，建立领域基本认知  
2. 沿参考文献 / Related Works / 对比方法 / AI 推荐，扩展重要文献  
3. 对代表性工作尝试代码复现，打好实验基础  

### Problem / Idea / Concrete Work

- 少部分问题由导师直接给出；多数需自己从文献空白与方法局限中提出，再请导师判断值不值得做  
- **宜「小题大做」、忌「大题小做」**：把一个具体问题做透，而不是对宏观大问题浅尝辄止  
- Idea 没有统一模板；相对而言，**找对问题后想 idea 往往不是最难的一步**（也可借助 AI 工具辅助，但仍需自己判断）  
- Concrete Work 需回答：Strength / Weakness、How–When Strong/Weak、Why Strong/Weak  

## 研究生的主要任务（研究相关）

1. 探索与构思新想法（大量检索与阅读）  
2. 用实验检验可行性（快速实现与严谨分析）  
3. 撰写论文并投稿（含同行评审与 Rebuttal）  
4. 评审他人投稿（作者身份的另一面）  
5. 参会、分享、交流与寻求合作  
6. 申请奖学金 / 项目经费  
7. 协助指导低年级同学（高年级常见）  
8. 参与课题组纵横向项目，把成果落到真实需求  

## 七项关键能力

1. **激情与专注**：能日复一日推动同一条问题线  
2. **好奇心与创造性**：追问本质，愿意进入前人较少涉足的地带  
3. **批判性与独立性**：不盲从；追问「哪里不合理、如何更好」  
4. **冒险精神**：多数想法会失败，仍要敢于试  
5. **学习与解题能力**：保持阅读与技术更新  
6. **勤奋**：好工作需要时间投入  
7. **表达与沟通**：写作、报告、申请、与导师/同行协作
