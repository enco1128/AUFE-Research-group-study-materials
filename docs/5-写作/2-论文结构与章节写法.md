# 论文结构与章节写法

> **AUFE课题组科研入门** · 对应论文章节：**Writing**  
> 来源：手册第十–十五篇 · 速查：[`resources/05-writing/`](https://github.com/enco1128/AUFE-Research-group-study-materials/tree/main/resources/05-writing)

## Abstract：五句话原则

1. **Context（1 句）**：领域与任务，少铺垫常识  
2. **Problem（1–2 句，最关键）**：写成**结构性问题**，避免只写「LLMs often fail in xxx」类经验现象  
3. **Methodology（1–2 句）**：凝练核心思想，让人看出「为何逻辑上能解决问题」  
4. **Results（1 句）**：具体可量化（数据集数、对比方法、指标幅度）；并与前文问题**闭环**  
5. （可并入 Results）贡献点点到为止，细节留给正文  

模板：[`abstract_five_sentences.md`](https://github.com/enco1128/AUFE-Research-group-study-materials/blob/main/resources/05-writing/abstract_five_sentences.md)

## Introduction：四段式 + 可复用骨架

**四段逻辑**

1. 建立研究领域  
2. 回顾已有研究  
3. 指出问题或研究空缺  
4. 引出本文工作  

**常见六段展开**

1. 大背景 → 2. 已有工作 → 3. 不足与 gap → 4. 本文方法 → 5. 贡献总结 → 6. 论文结构（可选）

骨架：[`intro_skeleton.md`](https://github.com/enco1128/AUFE-Research-group-study-materials/blob/main/resources/05-writing/intro_skeleton.md)

## Related Works

- 与 Introduction 分工：Intro 讲故事与 gap；Related 做系统定位与分类  
- 常见组织：按研究方向 / 按方法类别  
- 每段：引入方向 → 总结已有 → 指出不足 → 说明本文区别  
- 避免：流水账罗列、与本文无关的堆砌、贬低他人却无对比依据  
- 贡献定位关系：扩展 / 互补 / 正交 / 在相同设定下显著更优等  

## Methods：总分结构

1. **Overview**：先给全局图景  
2. **Problem Formulation**：形式化问题  
3. **公式必解释**：符号、含义、与模块的关系  
4. **Method Details**：按模块展开  
5. **伪代码**（可选）辅助算法流程  
6. **写清 novelty**：相对已有方法的关键差异  

## Experiments：七段结构（常用）

1. Experimental Setup（数据、指标、实现、对比方法）  
2. Main Results（服务核心结论，与 claim 对齐）  
3. Ablation Study（说明「为什么有效」）  
4. Analysis（加深理解）  
5. Case Study / Visualization  
6. （可选）局限与失败分析  
7. （可选）效率 / 鲁棒性等补充  

细节提醒：对比公平、指标与问题匹配、显著结论需有支撑；不要「挂羊头卖狗肉」。
