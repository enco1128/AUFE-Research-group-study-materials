> 来源：手册第九篇 · 配色与工具速查：[`figure_tips.md`](https://github.com/enco1128/AUFE-Research-group-study-materials/blob/main/resources/05-writing/figure_tips.md)  
> 完整案例配图见原文：[`resources/handbook/`](https://github.com/enco1128/AUFE-Research-group-study-materials/tree/main/resources/handbook)

## 本页目标

- 分清三类主图：动机图、方法图、结果图  
- 知道「好图」服务叙事，而不是装饰  
- 配齐配色与工具链  

## 总览：三类图

| 类型 | 作用 | 常见位置 |
|------|------|----------|
| **动机图（Teaser）** | 一眼看懂问题、gap 或本文相对优势 | 靠前 / Intro 附近 |
| **方法流程图（Main Figure）** | 模块、数据流、训练/推理流程 | Methods |
| **结果图表（Results）** | 主结果、消融、分析曲线、对比表 | Experiments |

也常见 **Related Works 对比表/图**：用维度、符号或文字对比多篇工作的设定差异。

## 动机图常见套路

1. **现有方法 vs 本文方法**：并排对比失败模式与改进  
2. **形象对比**：用直观隐喻降低理解成本（需准确，忌夸张误导）  
3. **具体例子驱动**：用一个 case 讲清痛点  
4. **方法概览缩略**：在 teaser 里给出 pipeline 鸟瞰  

## 方法图要点

- 输入 → 关键模块 → 输出路径清晰  
- 模块命名与正文小节一致  
- 训练/推理若不同，可分栏或分图  
- 避免信息过载：次要细节放附录或正文  

## 结果图/表要点

- **主结果表**：用底色/加粗/名次线标出本文；数字可读  
- **对比维度表**：数据集规模、模态、设定等（Related 亦常用）  
- **曲线**：可标注关键点、方差带、相对增益；服务分析结论  
- 所有图注应能**脱离正文**读懂关键信息  

## 工具与配色 Tips

1. **配色**：选有限色板并全篇统一；注意色盲友好与打印灰度  
2. **立体感**：适度阴影/层次，勿花哨喧宾夺主  
3. **矢量图标**：概览图/流程图优先矢量  
4. **架构工具**：draw.io、PPT、Illustrator、专业流程图工具  
5. **实验图**：Matplotlib / Seaborn / Plotly 等；导出矢量或足够 DPI  
6. **AI 草图**：可加速创意，定稿需人工精修与事实核对
