> **AUFE课题组科研入门** · 对应论文章节：**Writing**  
> 仓库资源：[`resources/05-writing/`](https://github.com/enco1128/AUFE-Research-group-study-materials/tree/main/resources/05-writing) · 手册第八篇起

## 本页目标

- 理解论文写作是「有逻辑的论证」  
- 写论文前先对齐署名、目标与**八句话故事线**  
- 配齐工具，并用周报形成稳定输出节奏  

## 写作心态

证明工作有意义、方法合理、证据充分。恪守学术诚信；句式可模仿优秀论文，难点在逻辑与贡献叙事。

## 写论文之前

1. **署名与贡献**：与导师确认作者顺序与每人贡献边界  
2. **目标 venue**：会议还是期刊？摘要截止 / 全文截止（见 [ccfddl.top](https://ccfddl.top/)）  
3. **八句话故事线**（先写清再分章展开）：  
   1. 领域大背景为何重要  
   2. 现有方法大致怎么做  
   3. 关键缺口 / 结构性问题是什么  
   4. 本文核心想法一句话  
   5. 方法如何逻辑上对准该问题  
   6. 主要实验设置与对比对象  
   7. 关键定量结论（与问题闭环）  
   8. 贡献列表（3 条左右）  

投稿前自问：这篇论文解决了什么重要问题？证据是否撑得住 claim？

## 工具箱

| 用途 | 推荐 |
|------|------|
| LaTeX 协作 | Overleaf（本仓库 `latex/`） |
| 文献 | Zotero |
| 画图 | draw.io / Visio / PPT→PDF / Illustrator；详见画图指南 |
| 训练可视化 | W&B；社区 Hugging Face |
| 翻译润色 | DeepL / Grammarly（仍需人工） |
| 预印本 | arXiv |
| 匿名开源 | [Anonymous GitHub](https://anonymous.4open.science/) |
| 读论文助手 | [Paper Copilot](https://papercopilot.com/)（结论须核对） |
| 会期 | [ccfddl.top](https://ccfddl.top/) |
