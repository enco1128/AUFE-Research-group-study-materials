# 写作、工具与投稿

> 对应论文章节：**Writing** · 仓库资源：[`resources/05-writing/`](https://github.com/enco1128/Research-group-study-materials/tree/main/resources/05-writing)

## 本页目标

- 理解论文写作是「有逻辑的论证」  
- 配齐常用工具  
- 用周报模板形成稳定输出节奏

## 写作心态

证明工作有意义、方法合理、证据充分。恪守学术诚信；句式可模仿优秀论文，难点在逻辑与贡献叙事。

## 工具箱

| 用途 | 推荐 |
|------|------|
| LaTeX 协作 | Overleaf（本仓库 `latex/`） |
| 文献 | Zotero |
| 画图 | draw.io / Visio / PPT→PDF / Illustrator |
| 训练可视化 | W&B；社区 Hugging Face |
| 翻译润色 | DeepL / Grammarly（仍需人工） |
| 预印本 | arXiv |
| 匿名开源 | [Anonymous GitHub](https://anonymous.4open.science/) |
| 读论文助手 | [Paper Copilot](https://papercopilot.com/)（结论须核对） |
| 会期 | [ccfddl.top](https://ccfddl.top/) |

科研示意图 MCP（自行评估）：[drawio-scientific-illustrator](https://github.com/icebird1998/drawio-scientific-illustrator)
