# 八周学习路径

> 对应论文章节：**Conclusion** · 个人计划模板：[`templates/learning_plan.md`](https://github.com/enco1128/Research-group-study-materials/blob/main/templates/learning_plan.md)

## 使用方式

1. 复制 `templates/learning_plan.md` 到个人笔记  
2. 每周对照下表打勾  
3. 网页正文与 Overleaf `latex/` 同序，可任选阅读介质

## 入门结束检查清单

- [ ] 能维护结构化文献 list
