# 文献检索与精读

> 对应论文章节：**Related Work** · 仓库资源：[`resources/02-literature/`](https://github.com/enco1128/Research-group-study-materials/tree/main/resources/02-literature)

## 本页目标

- 掌握检索渠道与筛选策略  
- 建立结构化文献 list  
- 按泛读→精读顺序读完第一篇领域论文并做笔记

## 检索渠道

- 中文入门：知网优质综述  
- 英文主渠道：Google Scholar、[arXiv](https://arxiv.org/)、[AMiner](https://www.aminer.cn/)、[PubScholar](https://pubscholar.cn/)  
- 代码绑定：[Papers with Code](https://paperswithcode.com/)  
- 权威性：CCF 列表；组内投稿目标见课题范式页附图

优先顶刊顶会：PR、TPAMI、TIP、TNNLS、AAAI、CVPR、ECCV、ICCV、ACM MM、NeurIPS 等。

## 筛选策略

1. 先读**英文综述**：方法、开放问题、数据、指标、前景  
2. 再筛：经典 / 顶会顶刊 / 有代码有数据优先  
3. 看不懂：社区解读可作辅助，结论必须回原文核对

## 文献 List（强制）

每条至少含：题目、作者、引用、时间、链接、代码、数据集。  
模板：[`literature_list.csv`](https://github.com/enco1128/Research-group-study-materials/blob/main/resources/02-literature/literature_list.csv)  
范例：[`icml_health_example.md`](https://github.com/enco1128/Research-group-study-materials/blob/main/resources/02-literature/icml_health_example.md)、[`pulmonary_embolism_example.md`](https://github.com/enco1128/Research-group-study-materials/blob/main/resources/02-literature/pulmonary_embolism_example.md)

## 阅读顺序

**泛读：** Abstract + 第一张总览图 → Introduction → Conclusion  
有价值再读 Method → Experiment。

精读后应能讲清：问题定义、背景不足、动机与框架、实验结论、对你课题的迁移点。

> 读懂第一篇常需 1–2 周；连带读十余篇相关工作是正常现象。

文献管理推荐 Zotero；笔记可用 Obsidian / Notion。

## 汇报 Checklist

论文汇报：Background / Challenge / Existing / Method / Dataset / Results / 批判性思考。  
扫描要点：[`literature_and_report_tips.pdf`](https://github.com/enco1128/Research-group-study-materials/blob/main/resources/02-literature/literature_and_report_tips.pdf)

周汇报：上周遗留 → 本周工作 → 卡点 → 下周计划。见写作篇模板。
