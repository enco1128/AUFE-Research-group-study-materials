## 本页目标

- 掌握**六条检索路径**与筛选策略  
- 建立结构化文献 list  
- 用**七步法**完成第一篇领域论文精读与笔记  

## 六条检索路径

1. **重要会议与期刊**：每次截稿/放榜后按关键词筛一轮；venue 因方向而异（ML：ICML/NeurIPS/ICLR；CV：CVPR/ICCV/ECCV；综合：AAAI 等；期刊：TPAMI/JMLR/…）。名单不是唯一价值标准，进方向后要建自己的重点 venue 表。  
2. **种子论文扩展**：高质量 Survey、公认代表作、最贴近你问题的论文、主流 Benchmark、近两年顶会、导师/同学推荐。  
3. **文献网络顺藤摸瓜**：Introduction / Related Works / Compared Methods / References；**向后**追早期工作，**向前**追引用、改进与质疑。  
4. **作者与课题组**：个人主页、Scholar/DBLP/S2、实验室主页、GitHub 组织、项目页、Hugging Face。  
5. **代码 / 数据 / Benchmark 生态**：官网、Leaderboard、HF Models/Datasets/Papers、仓库 Issues/PR、结果表中的对比方法。  
6. **日常信息流**：早间 arXiv、HF Daily Papers、Scholar 订阅、靠谱公众号/分享、AMiner / Bohrium / ChatPaper 等（结论仍须回原文）。  

中文入门可用知网优质综述；英文可用 Google Scholar、[arXiv](https://arxiv.org/)、[AMiner](https://www.aminer.cn/)、[PubScholar](https://pubscholar.cn/)、[Papers with Code](https://paperswithcode.com/)。

## 筛选策略

1. 先读**英文综述**：方法、开放问题、数据、指标、前景  
2. 再筛：经典 / 顶会顶刊 / 有代码有数据优先  
3. 看不懂：社区解读可作辅助，结论必须回原文核对

## 七步法读论文

> 每个 Topic 都有前后衔接的线索；某天把杂乱知识点串成一线，就会开始尝到研究的乐趣。

1. **宏观概览**：摘要 + 图表；单位、venue、类型、问题、效果  
2. **锁定核心研究问题**：Abstract / Introduction 转折处的真问题  
3. **梳理已有工作**：是否真问题？前人怎么做？还缺什么？若交给你会怎么做？  
4. **精读方法**：与自己设想对照，找局限与可改进点  
5. **分析与复现实验**：数据、对比、设置、结论、漏洞、代码；关键文尽量复现  
6. **顺藤摸瓜**：沿 Intro / Related / Compared Methods 补背景技术  
7. **读后思考**：建议约 **40% 读、60% 想**  
   - 批判性：假设是否成立？问题是否合理？方法有何缺陷？  
   - 创造性：若交给你，你会怎么做？优劣如何？  

精读后应能讲清：问题定义、背景不足、动机与框架、实验结论、对你课题的迁移点。读懂第一篇常需 1–2 周，连带读十余篇相关工作属正常。

可打印要点：[`literature_and_report_tips.pdf`](https://github.com/enco1128/AUFE-Research-group-study-materials/blob/main/resources/02-literature/literature_and_report_tips.pdf) · 七步速查：[`reading_seven_steps.md`](https://github.com/enco1128/AUFE-Research-group-study-materials/blob/main/resources/02-literature/reading_seven_steps.md)
