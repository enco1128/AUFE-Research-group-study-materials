\subsection{六条检索路径}
\begin{enumerate}
  \item 重要会议与期刊：每次截稿/放榜后按关键词筛选；venue 因方向而异，进方向后建立自己的重点列表。
  \item 种子论文扩展：Survey、代表作、最贴近问题的论文、主流 Benchmark、近两年顶会、导师/同学推荐。
  \item 文献网络顺藤摸瓜：Introduction / Related Works / Compared Methods / References；向后追早期工作，向前追引用与改进。
  \item 作者与课题组：主页、Scholar/DBLP、实验室、GitHub 组织与项目页。
  \item 代码/数据/Benchmark 生态：官网、Leaderboard、Hugging Face、仓库 Issues/PR、结果表对比方法。
  \item 日常信息流：arXiv、HF Daily Papers、Scholar 订阅、靠谱分享与检索平台（结论须回原文）。
\end{enumerate}
策略上先读英文综述建立地图，再筛选经典/顶会顶刊/有代码有数据的工作。每条文献记录应至少包含题目、作者、引用、时间、链接、代码与数据集字段；模板见 \path{resources/02-literature/literature\_list.csv}。

\subsection{七步法精读}
宏观概览 $\rightarrow$ 锁定核心研究问题 $\rightarrow$ 梳理已有工作 $\rightarrow$ 精读方法 $\rightarrow$ 分析与复现实验 $\rightarrow$ 顺藤摸瓜 $\rightarrow$ 读后思考（建议约 40\% 读、60\% 想，含批判性与创造性两问）。速查见 \path{resources/02-literature/reading\_seven\_steps.md}。读懂第一篇领域论文常需一至两周，并连带阅读十余篇相关工作，属正常现象。

\subsection{学术汇报}
PPT 以清晰可读为先：字体统一、每页少文字、关键高亮、目录导航。内容上优先高质量论文或方向 Tutorial，并站在听众角度补前置知识。汇报后应能用 2--3 句话概括贡献，并回答动机、方法、实验与后续想法等追问；清单见 \path{resources/02-literature/report\_questions.md}，网页见 \texttt{docs/2-文献/2-学术汇报.md}。周汇报结构见写作篇模板。
